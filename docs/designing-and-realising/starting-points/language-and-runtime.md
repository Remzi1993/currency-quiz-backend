# Language & Runtime

My backend uses Kotlin on the JVM. These examples connect the runtime concepts to the API code.

| Topic                         | Explanation and project example                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Code evidence                                                                                                                                                                   |
|-------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Logical layers                | Routing handles HTTP requests, security handles admin authentication, and the repository handles question storage. These are responsibilities within one application, not separate Gradle modules.                                                                                                                                                                                                                                                                                   | [Routing.kt](../../../src/main/kotlin/Routing.kt), [Security.kt](../../../src/main/kotlin/Security.kt), [QuestionRepository.kt](../../../src/main/kotlin/QuestionRepository.kt) |
| Compiler, interpreter and JIT | The [Kotlin compiler](https://kotlinlang.org/docs/compiler-reference.html) translates source into JVM bytecode before startup. An interpreter executes instructions; a JIT compiler translates code into machine code while the application runs. [HotSpot combines interpretation and compilation](https://docs.oracle.com/en/java/javase/25/vm/java-hotspot-virtual-machine-performance-enhancements.html). My Docker build uses JDK 25, then runs the JAR with a Java 25 runtime. | [build.gradle.kts](../../../build.gradle.kts), [Dockerfile](../../../Dockerfile)                                                                                                |
| Stack and heap                | Conceptually, [JVM stacks](https://docs.oracle.com/javase/specs/jvms/se25/html/jvms-2.html#jvms-2.5.2) hold method frames and local values/references; the heap holds objects and arrays. The repository's question map is an example of object data kept between requests.                                                                                                                                                                                                          | [QuestionRepository.kt](../../../src/main/kotlin/QuestionRepository.kt), [Models.kt](../../../src/main/kotlin/Models.kt)                                                        |
| Memory management             | [Garbage collection](https://docs.oracle.com/en/java/javase/25/gctuning/introduction-garbage-collection-tuning.html) reclaims unreachable object memory. Unnecessary references can keep data alive. I also use `.use` to close the seed reader: resource cleanup should not wait for garbage collection.                                                                                                                                                                            | [QuestionRepository.kt](../../../src/main/kotlin/QuestionRepository.kt)                                                                                                         |

The layers and reader cleanup are implementation evidence. The stack, heap and JIT explanations describe runtime behaviour; I have not measured memory usage or JIT performance.
